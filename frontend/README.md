# FX-Master Frontend

Next.js & React frontend for the FX-Master Fintech Landing Page.

## Features

- **Next-Gen Dark Fintech Design**: Obsidian backgrounds, emerald green and cyan neon glows, glassmorphism card surfaces.
- **Interactive Currency Swap**: Real-time recalculation of exchange amounts with zero markup.
- **Live Treasury Spline Chart**: Dynamic HTML5 Canvas rendering supporting 24H, 7D, 1M, 1Y, and ALL timeframes.
- **Interactive Savings Calculator**: Slider-driven transfer fee comparison vs traditional high-street banks.
- **Bento Grid Architecture**: Virtual IBANs, automated FX hedging, corporate cards, and API SDK preview.
- **Pricing Interval Switch**: Monthly vs Annual with instant 20% discount calculation.
- **Responsive Navigation**: Desktop sticky header + mobile drawer.

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

App runs on: `http://localhost:3000`
